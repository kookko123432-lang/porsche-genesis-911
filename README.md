# MY PORSCHE : GENESIS 911
**Stuttgart-Zuffenhausen 911-Day Commissioning & Mental Telemetry System (`2026.10.21` – `2029.04.18`)**

## 1. Android 手機安裝與桌面小工具啟用指南
1. 前往本專案的 **[Releases 頁面](../../releases/latest)** 下載 **`porsche-genesis-911.apk`**（或使用專案根目錄已編譯好的 `porsche-genesis-911.apk`）。
2. 在 Android 手機上點選安裝。
3. **新增 Android 桌面小工具**：
   - 長按 Android 手機主畫面空白處 ➔ 點選 **「小工具 (Widgets)」**
   - 找到 **「PORSCHE 911 // CHRONO WIDGET」** 並拖曳至桌面，即可隨時檢視 `DAY XXX / 911`、`T-XXX DAYS`（目標日 `2029.04.18`）與車主潛意識暗示。

## 2. 四大核心座艙模組
- **`00 WIDGET`**：桌面小工具預覽、早中晚防視覺麻痺視角切換、全螢幕 `NIGHT STANDBY` 紅光五環待機模式、鎖定畫面桌布匯出。
- **`01 CHRONO`**：10Hz 精密倒數時計、方向盤左側電門點火儀式、祖文豪森 10 階段原廠生產節點、李小龍《價值交換對價契約》180° 翻轉黑卡。
- **`02 COCKPIT`**：第一人稱夜間高速公路流光視角、360° 座艙平移、退檔補油聲浪（Rev-Match Blip）、四軌座艙環境聲學混音器（水平對臥六缸共鳴 ＋ 夜雨胎噪 ＋ 6Hz Theta 雙耳波 ＋ 車載肯定句電台）。
- **`03 2029` & `04 LOG`**：《Christophorus》雜誌風格的 2029 車主一日五章節有聲冥想、成功人士「外在生活秩序 vs. 內在決策作業系統」全息對照卡、親口錄音潛意識循環、369 拉絲金屬門檻手寫簽名板與車主手札。
